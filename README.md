# Tourism Management System (TMS)

## Project Overview

The Tourism Management System is a web-based application that helps users explore and book travel packages. It also provides an admin interface to manage tourism-related information.

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL
* AJAX and jQuery
* WAMPServer

## Features

* User registration and login
* Browse tourism packages
* Travel package booking
* Admin management
* Database integration

## Installation

1. Install WAMPServer.
2. Clone or copy this project into the WAMP `www` directory.
3. Import the project database using phpMyAdmin.
4. Configure the database connection in the project.
5. Open `http://localhost/tms/` in your browser.
